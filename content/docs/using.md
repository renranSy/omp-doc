# 使用 omp

## 交互式会话的剖析

直接运行 `omp` 会打开一个交互式会话。屏幕有四个区域，从上到下：

**Header**

首次启动时的 OMP 徽标，然后是对话开始后的紧凑会话标题：标题、 session tree 中的当前分支，以及任何活动模式横幅（计划、循环、目标）。

**消息**

用户提示、助理Turn和工具调用卡。每个工具调用都会呈现为一行摘要； Ctrl+O 展开该卡以显示完整输出、完整差异或完整 bash 脚本。

**编辑器**

多行输入，包括文件引用、路径完成、图像粘贴、shell 转义和 外部编辑交接。

**Footer**

两条暗线（当扩展发布状态时为三条）。第一行：工作目录和当前 git 分支。第二行：令牌计数器、成本、上下文使用和活动模型。

## 编辑器功能

| 特点 | 如何 | 它的作用 |
| --- | --- | --- |
| 文件参考 | `@` | 模糊搜索项目文件（尊重 `.gitignore`）。在发送时，每个引用都会替换为提示中内嵌的文件内容。 |
| 路径补全 | Tab | 完成相对路径， `../`, `~/`和类似的前缀。 |
| 多行 | Shift+Enter / Alt+Enter | 插入换行符。在Windows Terminal上使用 Alt+Enter （它不提供 Shift+Enter). |
| 图片附加 | Ctrl+V、拖放，或 `@image.png` | 从剪贴板粘贴、从操作系统文件管理器拖动或内联路径。活动模型必须接受图像输入，否则附件会在发送时丢弃并出现警告。 |
| Shell逃逸（可见） | `!` | 提示前缀为 `!` 作为 shell 命令执行并将输出包含在上下文中。实时流式传输。 Escape 取消。 |
| Shell逃逸（隐藏） | `!!` | 与相同 `!`，但不包括 LLM 上下文的输出。输出仍然流到您的终端。 |
| Python 转义 | `$` / `$$` | 在共享 Python 内核中运行。 `$$` 以同样的方式隐藏上下文中的输出 `!!` 对于 bash 来说。 |
| 外部编辑 | Ctrl+G | 打开当前草稿 `$VISUAL` / `$EDITOR`;退出时保存回编辑器。 |
| 迅速采取行动 | # | 打开当前草稿的提示操作菜单。 |

完整快捷键列表（历史搜索、行移动、复制快捷键、模型切换）请参阅 [快捷键](/docs/keybindings).

## 消息队列

在代理工作时键入，不会丢失任何内容。消息在中途队列中提交并在两条通道中排出。

| 快捷键 | 类型 | 送达时机 |
| --- | --- | --- |
| Enter | 转向信息 | 当前助手轮完成其工具调用后。用于在飞行中修正航向。 |
| Ctrl+Q / Ctrl+Enter | 跟进 | 智能体完成所有排队工作并生成回复后。用于“然后这个”。 |
| Escape | — | 中止当前回合。排队的转向和后续消息将恢复到编辑器堆栈而不是丢弃。 |
| Alt+Up | — | 将最新排队的消息出队返回编辑器。 |

三种设置塑造行为，下 `/settings` → *互动* 或作为顶级键 `~/.omp/agent/config.yml`:

-   `steeringMode` — `all` 或 `one-at-a-time` （默认）。
-   `followUpMode` — `all` 或 `one-at-a-time` （默认）。
-   `interruptMode` — `immediate` （默认）或 `wait`.

## 模式

交互式是默认设置。其他模式是选择的非交互式表面 `--print` 或 `--mode <mode>`.

| 模式 | 调用 | 输出 | 用于 |
| --- | --- | --- | --- |
| 交互式（默认） | `omp` | TUI | 日常工作。 |
| 打印 | `omp -p "prompt"` | 标准输出上的纯文本，没有 TUI。 | 脚本、CI、shell 管道。 |
| JSON | `omp --mode json -p "prompt"` | 标准输出上以换行符分隔的 JSON 事件。 | 形状稳定，可通过通过管道传给其他工具。 |
| RPC | `omp --mode rpc` | 通过 stdio 的 JSON-RPC。 | SDK 和编程客户端。参见 [RPC模式](/docs/rpc). |
| ACP | `omp --mode acp` （或 `omp acp`) | 基于 stdio 的Agent Client Protocol。 | 编辑者和其他 ACP 感知主机。参见 [ACP](/docs/acp). |

`--mode rpc-ui` 是一个变体 `rpc` 向客户端显示 TUI 内工具调用 UI。完整的Flag库存继续存在 [CLI 页面](/docs/cli).

## 计划模式

在涉及多个文件或顺序不明显的更改之前，先找到 计划模式。 `/plan` 将计划Turn沙箱化，以针对单独的计划器模型进行只读工作（它可能只写入其计划文件）；获得批准后，您可以选择执行和清除、保留记录或压缩上下文。完整流程请参阅 [计划模式](/docs/plan) 页。
